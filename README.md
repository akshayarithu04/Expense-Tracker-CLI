# Expense Tracker CLI

A Java Maven-based console application for managing daily expenses with CRUD operations.

## Features

* Add Expenses
* View All Expenses
* Update Existing Expenses
* Delete Expenses
* Filter Expenses By Category
* Calculate Total Expenses
* Custom Exception Handling
* Layered Project Architecture
* Maven Build Management

## Tech Stack

* Java 17
* Maven
* IntelliJ IDEA
* Collections Framework
 
## Maven Concepts Used

* Maven Project Structure
* pom.xml Configuration
* Maven Lifecycle
* Maven Plugins
* Dependency Management

## OOP Concepts Used

* Encapsulation
* Abstraction
* Custom Exception Handling
* Layered Architecture
* Object-Oriented Design

## Functionalities

### Add Expense

Users can add expenses with:

* Title
* Category
* Amount

### View Expenses

Displays all stored expenses.

### Update Expense

Users can update:

* Expense title
* Expense category
* Expense amount

### Delete Expense

Delete expense using expense ID.

### Filter By Category

Displays expenses belonging to a selected category.

### Total Expense Calculation

Calculates overall expense amount.
